Welcome to the Mojo Manual, the authoritative learning path for Mojo.

Mojo is the systems language for the AI era. It's a general-purpose
language for building the software that makes that world work: from
libraries and runtimes to databases, compilers, robotics, high-performance
computing, simulation, and systems that reach across hardware types. It's
built for a world of heterogeneous hardware and increasingly specialized
compute.

This manual is for developers and researchers who know how to program and
want to build those systems. You don't need experience with any particular
language. Bring your programming experience, your problem domain, and your
goals. This manual provides the path into Mojo.

## What you'll find here

The Mojo Manual starts with enough of the language to get you working
quickly, then goes deeper into the ideas that give Mojo its range.

Explore a programming model designed for reuse across types, workloads, and
hardware. See how compile-time parameters and constraints let one
abstraction describe whole families of use cases while preserving the
information needed to specialize each one. Mojo lets you work from
high-level abstractions down to direct control of values, memory, and
hardware, depending on what your problem demands.

The path continues into building systems with Mojo, including libraries and
infrastructure that other developers can build on.

Mojo is open source under the Apache License v2.0 with LLVM Exceptions.
There's lots of room to contribute. We welcome collaborators and value our
community.

## First day? First week? Start here

Ready to write some code? [Quickstart](/docs/manual/quickstart/) gives you
a fast tour of Mojo syntax and other fundamentals. It gives you just enough
context that you're ready to start exploring Mojo's conceptual material.
You can easily finish within 15-30 minutes, or take more time to savor the
syntax.

- Keep the [language reference](/docs/reference/) handy for syntax,
  keywords, and more.
- Download [cheat sheets](/docs/reference/cheat-sheets/) for printable
  reference cards that bring entire concepts together.

For a bigger project, build Conway's Game of Life with the [get started
tutorial](/docs/manual/get-started). It normally takes about 45-60 minutes.
[Mojo Quest](https://quest.mojolang.org/) lets you practice Mojo syntax
with tiny incremental coding challenges.

## Explore the Manual

- [Language basics](/docs/manual/basics/): Learn the core language:
  functions, variables, types, operators, control flow, error handling,
  structs, modules, and packages.
- [Value ownership](/docs/manual/values/ownership/): Understand how Mojo
  manages values, from value semantics and ownership to lifetimes, origins,
  and references.
- [Value lifecycle](/docs/manual/lifecycle/life/): Discover how to create
  and initialize values, and work with explicit and implicit destruction.
- [Metaprogramming](/docs/manual/metaprogramming/): Explore Mojo's
  compile-time model, including compile-time evaluation, parameterization,
  traits, constraints, materialization, and reflection.
- [Pointers](/docs/manual/pointers/): Work directly with memory when your
  program requires it, including Mojo's unsafe pointer types.
- Advanced functions: Create [closures](/docs/manual/functions/closures/)
  that capture local state and lightweight anonymous functions with [lambda
  expressions](/docs/manual/functions/lambda/).
- Interoperability: Learn how to call external code in
  [C](/docs/manual/c-ffi/) and [Python](/docs/manual/python/), and work
  with existing libraries and runtimes.
- Mojo tools: Set up projects, [compile and target different
  hardware](/docs/tools/compilation/), [test](/docs/tools/testing/), and
  [debug](/docs/tools/debugging/) programs, work in
  [notebooks](/docs/tools/notebooks/), and [package your
  code](/docs/tools/packaging/).

## Use Mojo with AI coding assistants

Many developers use AI coding assistants. To install the Mojo agent skills
for up-to-date information about the rapidly evolving language, use:

```bash
npx skills add modular/skills
```

This installs all [Mojo agent skills](/docs/tools/skills/), including the
`mojo-syntax` skill, which stays current with the latest nightly language
release.
