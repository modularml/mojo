MAX supports structured output using
[xgrammar](https://github.com/mlc-ai/xgrammar) as the default backend, and you
can switch to [llguidance](https://github.com/guidance-ai/llguidance).
Structured output, also called constrained decoding, lets you enforce specific
output formats so a model returns structured, predictable responses.

## When to use structured output

If you want to structure a model's output when it responds to a user, then you
should use a structured output `response_format`.

If you are connecting a model to tools, functions, data, or other systems, then
you should use [function calling](/serve/function-calling) instead of
structured outputs.

Learn more about
[structured output](https://handbook.modular.com/model-interaction/structured-outputs/)
in the LLM Inference Handbook.

## How structured output works

To use structured output, include the `--enable-structured-output` flag when
serving your model with the [`max` CLI](/cli).

```bash
max serve \
  --model "google/gemma-4-31B-it" \
  --enable-structured-output
```

You can tune structured output behavior with the following options:

- `--structured-output-backend`: Selects the grammar backend for constrained
  decoding, either `xgrammar` (the default) or `llguidance`. Some architectures
  declare their own default, but an explicit value on the command line
  overrides it.
- `--structured-output-any-whitespace`: Controls whether structured output
  grammars accept whitespace between JSON tokens. The default, `false`,
  constrains the model to compact JSON, which mitigates runaway output on some
  models. Pass `true` to allow whitespace-tolerant JSON.

:::note

The examples on this page use image input with a multimodal model. For
environment setup and additional image and video input options (including local
files), see [Image and video to text](/serve/image-to-text).

:::

Both the
[`/chat/completions`](/rest-api/create-chat-completion/) and
[`/completions`](/rest-api/create-completion/) API endpoints are
compatible with structured output.

You can define your structured output response format in two ways:

1. [JSON schema](#json-schema): Specify the schema directly in your request.
2. [Pydantic](#pydantic): Use Pydantic to define and validate your schema as a
   Python class.

We recommend testing your structured output responses thoroughly as they are
sensitive to the way the model was trained.

```python title="structured-image-description.py"
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")

response = client.chat.completions.create(
    model="google/gemma-4-31B-it",
    messages=[
        {
            "role": "system",
            "content": "You are an assistant that analyzes images and returns structured descriptions."
        },
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Analyze this image and describe what you see."
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/0052a70beed5bf71b92610a43a52df6d286cd5f3/diffusers/rabbit.jpg"
                    }
                }
            ]
        }
    ],
    max_completion_tokens=300,
    response_format={
        "type": "json_schema",
        "json_schema": {
            "name": "ImageAnalysis",
            "schema": {
                "type": "object",
                "properties": {
                    "description": {"type": "string"},
                    "subjects": {
                        "type": "array",
                        "items": {"type": "string"}
                    },
                    "colors": {
                        "type": "array",
                        "items": {"type": "string"}
                    },
                    "setting": {"type": "string"},
                    "mood": {"type": "string"}
                },
                "required": ["description", "subjects", "colors", "setting", "mood"],
                "additionalProperties": False
            }
        }
    }
)

print(response.choices[0].message.content)
```

### Pydantic

For production Python code, you can define your structured output using
[Pydantic](https://docs.pydantic.dev/latest/install/). This gives you type-safe
attribute access and automatic validation instead of manually parsing JSON
strings.

Here's an example using a Pydantic
[`BaseModel`](https://docs.pydantic.dev/latest/api/base_model/) to analyze an
image and return a validated response:

```python title="structured-image-analysis.py"
from pydantic import BaseModel
from openai import OpenAI

client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")

class ImageAnalysis(BaseModel):
    description: str
    subjects: list[str]
    colors: list[str]
    setting: str
    mood: str

completion = client.chat.completions.parse(
    model="google/gemma-4-31B-it",
    messages=[
        {
            "role": "system",
            "content": "You are an assistant that analyzes images and returns structured descriptions."
        },
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "Analyze this image and describe what you see."
                },
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://huggingface.co/datasets/huggingface/documentation-images/resolve/0052a70beed5bf71b92610a43a52df6d286cd5f3/diffusers/rabbit.jpg"
                    }
                }
            ]
        }
    ],
    max_completion_tokens=300,
    response_format=ImageAnalysis,
)

analysis = completion.choices[0].message.parsed
print(analysis)
```

### Supported models

All text generation models support structured output with MAX. As new models are
added, they will also be compatible with structured output. This functionality
is implemented at the pipeline level, ensuring consistency across different
models.

However, structured output currently doesn't support CPU deployments, only GPU
deployments.
